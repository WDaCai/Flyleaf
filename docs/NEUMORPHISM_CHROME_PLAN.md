# Flyleaf 浅色新拟物 Chrome 方案

> **已停用，仅留档。** 实现以 `THEME_BLEND_PLAN.md` 为准。不要再启用 `--neu-*` 双光源鼓包、外凸/内凹或卡内套娃。

> 归属：个人（Flyleaf / yan · lite WebView2）  
> 类型：UI / 体验皮肤（非交互架构重做）  
> 依据：StyleKit Neumorphism showcase；审核短评两轮；方案撰写 7 条 + 画面分析（默认行平、选中浅凹、正文更平、卡内不套娃）  
> 落地：本机 Cursor；`check` + `build:lite` 刷 `E:\Flyleaf`  
> 不宣称：全站已新拟物

---

## 1. 目标与非目标

**目标**
- 浅色主题的 **Chrome**（壳层：侧栏、顶栏、空状态卡片、主按钮/分段控件）对齐 StyleKit 新拟物触感。
- 与现有双主题、UX_V1.1、知识框架画布 **同一套尺度**（圆角/间距/字号/动效 token），只换浅色阴影语义。
- 用户能明确感知：可点的「鼓」、按下的「凹」、正文与画布仍然安静。

**非目标**
- 不重做信息架构、路由、数据层、框架画布逻辑。
- 不把深色主题改成深色新拟物。
- 不整站换紫 accent，不给编辑器正文 / 画布舞台与节点 / 命令面板结果列表硬套凸凹。
- 托盘壳不纳入本刀。
- 不做同步站、不做 Electron 大包、不改代码架构边界（core/ui/apps/shell-lite）。

---

## 2. 原则

1. **Chrome 可捏 / Content 别捏**  
   壳层控件吃凸凹；长文编辑区与画布内容区保持平面，焦点靠光标、选区、节点高亮。
2. **浅 = StyleKit；深 = 现有**  
   两套皮肤，不是同一皮肤换色。设置文案建议：`浅色 · 新拟物` / `深色 · 现有`。
3. **默认行平、选中浅凹**（画面分析）  
   侧栏未选中行：近平或极轻凸；选中/激活：浅 inset，不用整行深凹、不用粗边框。
4. **正文更平、卡内不套娃**  
   空状态可以有一张外凸大卡；卡内部按钮不要再叠一层鼓包卡片。
5. **Accent 局部**  
   仅主按钮文字/图标、选中条（如 `border-l` 细条）、掌握度点等；禁止大面积填充紫底。

## 3. Token 表（浅色新拟物）

> 仅在 `theme === light`（或等价）时启用。深色继续走现有 CSS 变量，不映射下列阴影。

### 3.1 表面

| Token | 值 | 用途 |
|-------|-----|------|
| `--neu-bg` | `#e0e5ec` | 窗口/侧栏/顶栏统一底，**禁止纯白/纯黑底** |
| `--neu-bg-secondary` | `#d1d9e6` | 略深一层表面（分组底、凹陷槽轨道），慎用 |
| `--neu-bg-alt` | `#f0f0f3` | 仅当现有代码已用此浅灰时兼容；新组件优先 `--neu-bg` |

### 3.2 双光源阴影（光源固定左上）

| Token | box-shadow | 语义 |
|-------|------------|------|
| `--neu-convex` | `8px 8px 16px #b8bcc2, -8px -8px 16px #ffffff` | 默认外凸（可点） |
| `--neu-convex-hover` | `4px 4px 8px #b8bcc2, -4px -4px 8px #ffffff` | hover：影变弱 |
| `--neu-concave` | `inset 4px 4px 8px #b8bcc2, inset -4px -4px 8px #ffffff` | active / 选中浅凹 |
| `--neu-concave-deep` | `inset 8px 8px 16px #b8bcc2, inset -8px -8px 16px #ffffff` | 仅轨道/进度槽等，**列表行禁用** |

实现：只用 `box-shadow`，禁用 `filter: drop-shadow`、单侧影、渐变底。

### 3.3 圆角与边框

| Token | 建议 | 说明 |
|-------|------|------|
| 圆角 | 沿用现有 `xl` / `2xl` 档（≥12–16px 量级） | 新拟物禁止尖角；与 UX_V1.1 同一尺度表 |
| 边框 | 默认无 border | 例外：accent 选中可用 `border-l-4`（或现有细条 token），禁止粗全包边框 |

### 3.4 动效

| 项 | 约定 |
|----|------|
| 时长 | **优先现有 duration token**；视觉上限 ≤300ms（StyleKit `duration-300`） |
| 缓动 | 现有 ease；阴影过渡 `ease-in-out` |
| 禁止 | `transform: translate` 上浮/下沉；active 只切换凸→凹，不位移 |

### 3.5 Accent（可选，不整站换）

| Token | 示例 | 用法 |
|-------|------|------|
| `--neu-accent` | `#6d5dfc`（可映射现有柔和撞色，不必强行紫） | 图标/文字/左侧条/小圆点 |
| 填充 | 主按钮可用极浅 accent 底 **或** 保持 neu 灰底 + accent 字色 | 禁止饱和大块填色按钮（StyleKit Don't） |

### 3.6 深色策略

- 深色主题：**零改**新拟物阴影与 `#e0e5ec` 底。
- 主题切换 = 换皮肤类名/数据属性；禁止「深色硬套浅色双光源」。
- 默认：跟随系统；若无系统偏好则浅色新拟物；**永远尊重并持久化用户上次选择**。

## 4. 组件落点清单

### 4.1 吃新拟物（本刀必做）

| 组件 | 默认 | hover | active/选中 | 备注 |
|------|------|-------|-------------|------|
| 主按钮（新建笔记等） | convex | convex-hover | concave | 可点主 CTA |
| 分段控件（大纲\|画布、视图切换） | 轨道 concave 浅；滑块/项 convex | 影弱 | 选中项 concave 或 inset | 对标 StyleKit toggle 思路 |
| 顶栏图标钮 | 轻 convex 或平+hover 凸 | 影弱 | concave | 尺寸保持现有 |
| 侧栏笔记行 / 文件夹行 | **平或极轻凸** | 轻凸/影弱 | **浅凹** + 可选 accent 左条 | 禁止整行 deep concave |
| 空状态外层大卡 | convex | 可不变 | — | 卡内按钮吃主按钮样式，**不套娃再套卡** |

### 4.2 明确豁免（保持现状 / 平面）

| 区域 | 原因 |
|------|------|
| 编辑器正文（含标题、段落、代码块） | Content 别捏；长文安静 |
| 画布舞台背景、网格、连线 | 可读性优先 |
| 画布节点卡片 | 已有形状；再凸凹易糊（画面：卡内不套娃） |
| 命令面板 **结果列表** | 审核：列表本刀不硬套凸凹；面板壳可轻处理但结果行保持平 |
| 托盘壳 | 审核：不纳入本刀 |
| 危险确认对话框内容区 | 沿用 Craft 式确认语言；不要更鼓的「假安全」 |

## 5. 交互反馈

### 5.1 必须有

- 可点 Chrome 控件：可见 hover 影变弱、active 外凸→内凹（无位移）。
- 主路径保存成功、删除进 trash：保持现有 status 与确认；本刀只换壳，不删这些反馈。
- 侧栏选中：浅凹 +（可选）accent 左条；与「当前笔记」状态一致。
- 危险操作（删笔记、清空、删框架枝）：**保持现有确认/trash 语义**，不因新拟物省略确认。
- 主题切换：切换后 Chrome 立即应用对应皮肤；无纯白/纯黑闪边。

### 5.2 禁止整行凹陷的场景

- 侧栏未选中的默认行。
- 命令面板结果每一行。
- 画布内节点行/节点卡。
- 编辑器每一行（含 gutter）。
- 空状态大卡内部的说明列表行。

## 6. 界面范围（只改 Chrome 三块）

本刀设计/实现范围仅：

1. **侧栏 + 顶栏**（含侧栏列表行触感、顶栏图标钮、窗口浅色底）  
2. **空状态**（无笔记 / 无框架：一张外凸大卡 + 主按钮；卡内文案与次要操作保持平）  
3. **分段控件 + 主按钮**（大纲\|画布等 segmented；主 CTA）  

**正文编辑器、知识框架画布舞台与节点：标注「保持现状」**，截图/验收时不要求凸凹。

界面说明（给实现，不必出独立设计稿文件）：
- 浅色三屏同一 `--neu-bg`；主按钮在空状态与顶栏语义一致。
- 分段：当前项浅凹，非当前轻凸。
- 深色三屏：与现网像素级可接受差异内（本刀不改）。

## 7. 与 UX_V1.1 / 框架画布衔接

| 来源 | 衔接方式 |
|------|----------|
| UX_V1.1 Bear 排版 / Focus | 编辑器继续吃；本刀不改正文排版 |
| Obsidian 侧栏密度 | 行高/缩进/字号沿用 V1.1；只换浅色行阴影语义 |
| Craft 危险确认 | 文案与流程不变 |
| 暖纸少阴影 | **深色与正文**继续少影；浅色 Chrome 例外走双光源 |
| 框架画布 draw.io 外观 | 工具栏按钮可吃新拟物；节点/网格/连线不吃 |
| `FRAMEWORK_CANVAS_PLAN` | 数据与交互本刀不动；仅可能共用顶栏/分段皮肤 |

尺度：圆角、间距、字号、duration **共用现有 token 表**，禁止另起一套 spacing。

## 8. 禁止项（审核强制 + StyleKit Don't）

- 禁止纯白 / 纯黑作为浅色窗口或卡片底。  
- 禁止渐变底、单侧影、`drop-shadow`、粗全包边框。  
- 禁止 active 时 `translate` 上浮。  
- 禁止整站换紫 / 大面积饱和填充按钮。  
- 禁止编辑器正文、画布节点/舞台、命令结果列表、托盘壳硬套凸凹。  
- 禁止深色主题套用 `#e0e5ec` 双光源。  
- 禁止卡内套娃鼓包。  
- 禁止本刀改数据层 / 宣称「全站已新拟物」。

## 9. Cursor 验收清单（≤8 条）

1. 浅色下：主按钮、分段控件可见 convex → hover 影弱 → active concave，且无位移。  
2. 浅色侧栏：默认行平（或极轻凸）；选中行为浅凹，非 deep inset。  
3. 空状态：外卡外凸；卡内无第二层鼓包卡；主按钮可点反馈正确。  
4. 深色主题：视觉与现网一致，无新拟物灰底/双光源。  
5. 编辑器长文滚动、命令面板结果列表、画布拖节点：无新增凸凹闪烁或手感回退。  
6. 主题切换（浅↔深）无纯白/纯黑闪边；用户选择可持久化。  
7. Accent 仅局部（字/图标/左条/点），非整站紫底。  
8. `check` + `build:lite` 通过，产物刷至 `E:\Flyleaf`；README/说明不写「全站新拟物」。
