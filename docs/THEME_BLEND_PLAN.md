# Flyleaf 气质融合主题方案（THEME_BLEND）

> 归属：个人（Flyleaf / yan · lite WebView2）  
> 类型：UI / 双主题气质融合（非架构重做）  
> 依据：星程拍板四套融合 + 三方商量收紧；覆盖/取代浅色新拟物鼓包路线（`NEUMORPHISM_CHROME_PLAN` 作试验品，**本刀停用新拟物**）  
> 落地：本机 Cursor；`check` + `build:lite` 刷 `E:\Flyleaf`  
> 口径：浅「温暖可读」/ 深「冷静聚焦」；不宣称四套皮肤全量 1:1 复刻  
> 壳层纸纹、空状态和主按钮以 `UI_DOODLE_SHELL_PLAN.md` 为准：空状态不再用中间大白卡，主 CTA 为签字笔 P1。

---

## 1. 目标与非目标

**目标**
- 用一套共用尺度（圆角/间距/字阶），做出两种清晰氛围：  
  - **浅色**：Craft 纸感 + Bear 暖灰可读 →「温暖可读」  
  - **深色**：冷静暗壳 + Linear 灰阶/细边/密度点缀 →「冷静聚焦」（表面可偏 Bear 炭灰，**不**整页硬改 Linear `#08090a`）
- Accent：**一主一辅**——Bear 橙为主；Linear 紫仅辅（focus/选中/链接）。
- Chrome 可有节制生动；Content（编辑器/画布）安静。
- 保留保存成功 status、删除→trash 确认与既有危险操作语义。

**非目标**
- 不做毛玻璃 / backdrop-blur（WebView2 风险；Kiyoshi **只借留白与柔分隔**，不借 blur）。
- 不停用之外还扩新拟物：双光源鼓包、外凸→内凹整行、卡内套娃。
- 不做架构重写、Electron 大包、同步站、导图大图谱虚拟化膨胀。
- 不做双主色、浅色整站紫、bounce/elastic、正文装饰动效。

---

## 2. 原则

1. **角色混合，不是拼盘**  
   Craft→浅色纸感与圆角尺度；Bear→浅暖灰字色/深炭灰倾向与橙主色；Linear→深色细边、灰阶层级、命令/列表密度点缀；Kiyoshi→留白与柔分隔（无 blur）。
2. **Chrome 可捏感用色阶/细影，不用鼓包**  
   可点态靠 hover 色阶、≤2% scale、细单层柔影；禁止 StyleKit 双光源凸凹。
3. **Content 别捏**  
   编辑器正文、画布舞台/节点/连线：零装饰动效、无闪烁阴影。
4. **浅深共用尺度，分家氛围**  
   同一 radius/spacing/type scale；颜色与边框语义分主题。
5. **一主一辅 accent**  
   主：Bear 橙（CTA、关键状态点）；辅：Linear 紫（focus ring、选中细条、链接）。禁止两色同时当大按钮底。

## 3. Token 表草案

> 名称可映射现有 CSS 变量；实现时合并进主题表，删除/停用 `--neu-*` 双光源在浅色路径的引用。

### 3.1 共用尺度（浅深同一套）

| Token | 建议 | 说明 |
|-------|------|------|
| Radius | Craft 档：`md` / `xl` / `2xl`（≥12–16px 量级） | 浅深共用 |
| Spacing / 字阶 | 沿用 UX_V1.1 / 现有 type scale | 禁止另起一套 |
| Duration | 现有 duration token；Chrome 动效 **≤150ms** | 见 §5 |
| Motion | 尊重 `prefers-reduced-motion: reduce` → 动效降为即时切色/无 scale | 强制 |

### 3.2 浅色「温暖可读」（Craft 纸 + Bear 暖灰）

| Token | 草案 | 用途 |
|-------|------|------|
| `--bg-app` | 暖纸白/米白（非纯白、非 `#e0e5ec` 新拟物灰） | 窗口底 |
| `--bg-chrome` | 略暖的浅灰 | 侧栏/顶栏 |
| `--bg-elevated` | 纸白卡片 | 空状态卡、弹出层 |
| `--text-primary` / `--text-muted` | Bear 倾向暖灰字阶（深灰而非冷灰） | 正文/次要 |
| `--border-subtle` | 低对比暖灰细边 | 分隔；Kiyoshi 柔分隔用此，不用 blur |
| `--shadow-soft` | **单层**柔影（如 `0 1px 3px rgba(0,0,0,.06)` 量级） | 卡/菜单；禁止双光源 |
| `--accent-primary` | Bear 橙（主） | 主按钮、关键点 |
| `--accent-secondary` | Linear 紫偏淡（辅） | focus/链接；浅色克制使用 |

### 3.3 深色「冷静聚焦」（暗壳 + Linear 点缀）

| Token | 草案 | 用途 |
|-------|------|------|
| `--bg-app` | Bear 炭灰倾向（约 `#21252B` 量级） | 主表面；**禁止**整页硬改 `#08090a` |
| `--bg-chrome` | 略深/略浅一档灰阶 | 侧栏/顶栏；细边区分，无毛玻璃 |
| `--bg-elevated` | Linear 式抬一层灰 | 面板/菜单 |
| `--border-subtle` | Linear 细边（低对比灰） | 分割线、输入框 |
| `--text-primary` / `--text-muted` | 高对比浅字 + 静音灰 | 专注可读 |
| `--shadow-soft` | 极轻或靠边框分层（深色少影） | 避免脏雾 |
| `--accent-primary` | Bear 橙（主） | CTA、掌握度/状态点 |
| `--accent-secondary` | `#5e6ad2` 量级紫（辅） | focus ring、选中条、链接 |

### 3.4 停用（本刀）

| 停用项 | 说明 |
|--------|------|
| `--neu-convex` / hover / concave / deep | 双光源鼓包全停 |
| 毛玻璃 / `backdrop-filter: blur` | WebView2 风险；Kiyoshi 不借 blur |
| 整页 `--bg-app: #08090a` | 允许局部近黑（如命令面板内）但不做整页抠黑 |

## 4. 组件落点与豁免

### 4.1 本刀要吃主题的 Chrome

| 组件 | 浅色 | 深色 | 备注 |
|------|------|------|------|
| 窗口/侧栏/顶栏底 | 暖纸 + 暖灰壳 | 炭灰壳 + 细边 | 无 blur |
| 侧栏笔记/文件夹行 | 默认平；hover 色阶；选中浅底或辅色左条 | 同结构；密度可略收但不极密 | 禁止整行深凹鼓包 |
| 顶栏图标钮 | Craft 干净；hover ≤150ms | 细边/色阶 | scale≤2% 可选 |
| 主按钮 | 橙主色底或橙字 | 橙主色 | 禁止紫大按钮底 |
| 分段控件 | Craft 圆角轨道 | Linear 细边轨道 | 选中态色阶，不双光源 |
| 空状态大卡 | 纸感卡 + 单层柔影 + 轻趣味文案/插画位 | 抬层灰卡 | 卡内不套娃第二卡 |
| 命令面板 **壳** | 可用 elevated | Linear 密度壳 | **结果列表行保持平** |

### 4.2 明确豁免 / 保持安静

| 区域 | 约定 |
|------|------|
| 编辑器正文（含 Focus） | 零装饰动效；深色专注时排版沿 UX_V1.1 Bear |
| 画布舞台/网格/连线/节点 | 保持现状可读；节点不新材质 |
| 命令面板结果列表行 | 不行级鼓包/弹跳 |
| 托盘壳 | 非本刀（与前审一致可不纳入） |
| 危险确认 | Craft 式确认文案与流程保留 |

## 5. 交互允许 / 禁止

### 5.1 允许（Chrome · 生动有节制）

- Hover/选中：**≤150ms** 色阶或透明度变化。  
- Press：可选 **≤2% scale**（无 bounce、无 elastic、无 spring 过冲）。  
- 分段滑块、选中条：短位移或宽度过渡 ≤150ms。  
- 空状态：轻趣味（文案/静态插画/极轻入场 opacity）。  
- 主题切换：短淡入（opacity crossfade），无闪纯白/纯黑边。  
- **必须保留**：保存成功 status；删除→`.yan/trash` 确认与可恢复语义。

### 5.2 禁止

- 新拟物双光源、整行 inset 鼓包、卡内套娃凸凹。  
- bounce / elastic / 长 spring；正文或画布上的装饰动效、阴影闪烁。  
- 毛玻璃 blur。  
- 双主色（橙紫同时当主 CTA）；浅色整站紫。  
- 无视 `prefers-reduced-motion`。

## 6. 界面范围

本刀只改/验收：

1. **侧栏 + 顶栏**（双主题色与细边/柔分隔）  
2. **空状态**（纸感/抬层卡 + 主按钮 + 轻趣味，无套娃）  
3. **分段 + 主按钮 + 主题切换表现**  

正文编辑器与知识框架画布：**标注保持现状**（可继承字色/背景 token，但不加 Chrome 动效）。

## 9. Cursor 验收清单（≤8）

1. 浅色一眼「温暖可读」（暖纸/暖灰），无新拟物双光源鼓包。  
2. 深色一眼「冷静聚焦」（炭灰壳+细边），非整页 `#08090a` 抠黑。  
3. 主按钮/关键 CTA 为 Bear 橙；紫仅出现在 focus/选中条/链接等辅位。  
4. 侧栏+顶栏+空状态+分段在浅/深均正确；空状态卡内无套娃鼓包。  
5. Chrome 动效 ≤150ms、scale≤2%；开启 reduced-motion 时无 scale/无过渡闪烁。  
6. 编辑器长文与画布拖线：无新增装饰动效或阴影闪烁。  
7. 保存有 status；删除进 trash 且确认保留。  
8. `check` + `build:lite` 通过并刷 `E:\Flyleaf`；说明不写「全站四套复刻/已新拟物」。
