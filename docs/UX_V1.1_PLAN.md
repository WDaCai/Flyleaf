# Flyleaf UX v1.1 方案（调研 + 可执行）

约束沿用：lite WebView2；不做同步/云；不以 Electron 为主；不架构重写；删/分类走 core。

## 对标调研（抄交互，不抄功能堆）

| 产品 | 可抄 1～2 点 | 明确不抄 |
|------|-------------|---------|
| **Bear** | 排版优先（行高/段距/最大读宽）；Focus 一键藏侧栏；主题成套不散改色 | 标签替代文件夹（我们已有文件夹，保持） |
| **Obsidian Minimal** | 侧栏字号小于正文；文件名单行省略；编辑区聚焦时 chrome 变轻 | 插件宇宙 / 丝带条 |
| **Craft** | 块级操作可发现；删除/移动有清晰 affordance | 重度 block 数据库 |
| **Notion** | 渐进披露、即时反馈；空白页给清晰下一步 | 空白画布吓新人、全家桶数据库 |
| **Capacities / Heptabase** | 暖纸色底、少阴影靠发丝线与留白；色只作信息 | 无限白板 / 对象类型体系 |

## 本轮必须做（给 Cursor）

### A. 阅读舒适（Bear / Heptabase）
1. 编辑区：正文 `line-height` ≥ 1.7；标题/列表垂直节奏用 token（`--leading-body` / `--leading-ui`）
2. `--editor-max` 可在设置或命令里三档（窄/中/宽，约 680 / 820 / 960）
3. 侧栏字号保持 `sm/xs`，正文保持可读；侧栏行高略松（树节点不挤）

### B. Focus 模式（Bear / Obsidian Minimal）
1. 快捷键（如 `Ctrl+\` 或沿用现有）切换：藏左栏+右栏，只留编辑区
2. 顶栏极简（标题 + 保存状态）；`prefers-reduced-motion` 尊重

### C. 危险操作与空状态（Craft / Notion 反面教材）
1. 删除/永久删除/移分类：菜单分组清晰，danger 与普通项分隔（已有则再顺）
2. 空库/空文件夹：1～2 个真动作（新建笔记、打开收件箱），禁止假可点
3. 回收站：侧栏入口列出 `.yan/trash` 最近项 +「还原」调 notes.rename/move 回原分类（若路径丢了则还原到 inbox）

### D. 命令与反馈
1. 命令面板补：Focus、读宽、还原最近删除、设为收件箱
2. 状态条短反馈：已移入回收站 / 已还原 / 已设收件箱（可自动消失）

### E. 视觉收敛（Capacities 气质，不换主题体系）
1. 少投影，多用 1px 边与间距分层
2. 暖中性纸感已有则微调对比：侧栏与编辑区背景差一档即可，不要花
3. 按钮/树选中态用现有撞色，面积小、不刷屏

## 可后置
- 应用内完整回收站浏览器、多选批量删
- 标签体系、反向链接增强、导图虚拟化
- ShowCard bridge、多库切换、Yan* 改名
- Electron 大包叙事

## 明确不做
- 同步 / 云盘 / 多端实时
- 网站当主产品、看板日历第二大脑全家桶
- 推倒 tokens / 换编辑器内核 / 空拆包「伪模块化」

## 验收（必须自动化 + 手测）
1. `npm run check` 通过
2. `npm run build:lite` 刷到 `E:\Flyleaf`
3. Focus 开关正常，reduced-motion 下无猛动画
4. 删除→回收站→侧栏还原成功
5. 读宽三档切换可见；空状态无假按钮

## 实现顺序
1. tokens：leading / editor-max 档
2. Focus 模式
3. 回收站还原入口
4. 命令面板 + toast 式 status
5. 侧栏/空状态微调
6. check + build:lite + 简短手测记录写回 `docs/UX_V1.1_VERIFY.md`

## 补充：三位助手对齐（2026-10-28）

### 审核配比
- 硬能力（trash/inbox/分类/安装）已落地则本轮以「更安静、更跟手」收口
- 美化不得冲淡删除可逆叙事与空状态真动作
- 学节奏与密度，不学功能清单

### 撰写必做补强
- 空状态三件套（无笔记/空文件夹/空回收站）
- 删除→trash + 短反馈/还原入口；清空 trash 才二次确认
- 侧栏 inbox 标记与选中态；编辑区字号/行高/内容宽
- 双主题对比度再扫

### 美术执行
- 正文 15–16px、行高 1.6–1.75；侧栏 13–14px
- 浅暖纸 / 深冷夜；分隔优先留白与阶差；圆角 4–8；阴影极淡或无
- 焦点极淡；强调色低饱和同色相两套映射
