# 知识框架 · 大纲/导图打磨方案（本机 Cursor）

依据：DESIGN.md 8.5 / 15；方案撰写提纲；美术视觉要点。约束：lite；不重写 Framework/MindMap；不做同步/白板/全局图谱。

## 必须做

### 1. 空状态与入口
- 无 `type: framework` 笔记时：一句话 + 主按钮「新建框架笔记」（落到 `50-frameworks` 或当前 folders 里 frameworks 类路径；没有则 inbox 旁建）
- 打开空框架（只有标题无子节点）：提示如何用缩进列表加子项（可链到 Markdown 说明里框架一节）

### 2. 大纲
- 缩进层级清晰；四档掌握度点击切换（已有则打磨选中/焦点不打架）
- 折叠/展开状态用 localStorage 按框架 path 记住

### 3. Ctrl+M 对齐
- 大纲 ↔ 导图切换时保持同一选中节点（导图高亮该节点；回大纲滚到对应行）

### 4. 导图视觉（黑白柔和）
- 气质：纸上铅笔图，非彩虹脑图
- 边：1px 低对比 token 色（去掉硬编码 `#2b323c`），缓曲线，无花哨箭头
- 节点：走 token 填充/描边；圆角 4–8；文字略小于编辑正文一档
- 掌握度：轻量色点/glyph（已有 state-* token），不抢标题
- 选中：抬半级底 + 字重；悬停更弱；禁止粗亮边大阴影
- 浅暖纸 / 深冷夜映射；全部 token 化

### 5. 导图交互
- 点击节点 = 选中并与大纲行对齐；双击折叠子树（已有则验证）
- 滚轮缩放 + 拖动画布可用

### 6. 删除安全
- 删节点/子树：确认；若会动到独立笔记文件，走 trash 语义，不静默硬删
- 仅改框架 md 行则确认后写回即可

### 7. 性能
- ≤200 节点不虚拟化；超过 toast「建议拆成多棵框架」

## 可后置
拖拽改层级、导图内改标题、多选掌握度、导出图、虚拟化、跨笔记全局图

## 不做
换图库/重写架构、同步协作、插件、自由白板、Electron 主路径

## 验收
1. 空库 ≤2 步建出根+子节点
2. 四档掌握度可改且保存；折叠重启仍在
3. Ctrl+M 选中对齐
4. 导图缩放平移；点节点回大纲；硬编码描边清除
5. check + build:lite → E:\Flyleaf；写 docs/FRAMEWORK_VERIFY.md

## 审核对齐（必守）
- 导图单击只导航，不建文件；建文件仅大纲「＋」
- 两视图折叠/高亮/当前节点一致；适应窗口可用
- 不虚拟化、不换布局引擎、不另存结构
- 工具栏/节点无乱码
