# 纸感 + 签字笔壳层（定稿）

> 归属：Flyleaf lite 壳层（侧栏、空状态、主按钮）  
> 依据：扉页小人、侧栏纸样。现用「B 柔晕 + C 强调线」整合：主按钮和侧栏同一气质。  
> 口径：签字笔只做边缘和交互。不是涂鸦本。不回退 draw.io 嵌入。

气质融合方案里的「空状态中间大白卡」以本文为准：主区空状态贴在纸上，不再套一张抬层卡。

## 定稿

- **Logo**：左上角用现成小人图 `/favicon.png`（与 `shell/lite/flyleaf-icon.png` 同一张扉页图），圆角小方，旁边写「Flyleaf」。叶标不代替 Logo，只出现在底栏便签。
- **侧栏**：浅色有轻纸纹和右侧装订孔；分区标题旁一枚书签；「新建」是小缎带。提示只留短句（例如「或从随记打开」）。底栏仍是篇数和状态，外面包一层便签。深色少纸纹、装订孔更淡，书签和便签还在，但不铺浅色纸。
- **空状态**：无中间大白卡。淡水印是同一张小人（浅色 `multiply`，深色更淡）。只有一颗主按钮。没有笔记时是「新建笔记」；已有笔记但没打开时是「打开第一篇笔记」。没有知识框架时，「新建知识框架」是次要文字链，不是第二颗橙按钮。
- **柔晕 + 强调线**（B 水彩柔晕 + C 手绘强调线，主按钮和侧栏同一气质）：主按钮常态是墨线框、纸色底。悬停时半透明水彩从左侧慢慢晕开（约 360ms，边缘是渐隐，不是硬切），同时手绘波浪下划线变长。按下晕染更满、略深，下划线还在并略加重，字保持清晰。侧栏「新建 / 搜索 / 文件夹 / 回收站」和笔记行：悬停是淡橙柔晕（约 420ms，大约七成）加左侧一根竖墨条长出来。按下晕得更满。选中行用更淡、更慢的柔晕（约 680ms），左侧墨条保持显示，色层在文件名下面。减动时不做晕开和生长，主按钮与侧栏改成两档淡色块，侧栏左边条直接出现。空状态「新建知识框架」仍是文字链。
- **动效**：其余壳层仍用 `--dur-fast`（140ms）。柔晕和墨条用上面的较慢时长。编辑器正文和 draw.io iframe 不加这些装饰，内容区切换也不再做位移动效。

## 明确不动

- 笔记删除、回收站确认与还原。
- 随记窗口的拖边改大小和 `shell.txt`。
- draw.io 的加载、迁移和自动存盘。
- 框架大纲里的「添加节点」、打开库、回收站「返回笔记」仍是实心主按钮，不改成 P1，避免内容区跟着涂。

## 验收

1. 浅色：左上角是抱书小人加「Flyleaf」；侧栏有纸纹、装订孔、书签；底栏是便签加叶标，状态还在。
2. 空库：主区没有大白卡；一颗描边「新建笔记」。悬停时水彩从左侧慢慢晕开，边是柔的，下面的波浪线变长；按下晕得更满，字仍清楚。边框保持墨色。下面是下划线「新建知识框架」。
3. 侧栏「新建 / 搜索 / 文件夹 / 回收站」和笔记行：悬停是淡橙柔晕慢慢铺开，左侧墨条变长。按下晕得更满。选中行更淡、更慢，墨条留着，文件名始终在色层上面。
4. 深色：纸纹几乎没有，装订孔很淡；小人 Logo、柔晕和墨条仍在。
5. 系统「减少动态效果」打开后，没有晕开或生长，只有两档淡色块；侧栏左边条直接出现。
6. 打开笔记或画布：正文和 draw.io 没有纸纹动画，存盘行为与改壳前相同。
