# Markdown 写法说明（Flyleaf 白话版）

> 这篇是内置说明书。不会写 Markdown？命令面板（`Ctrl+P`）搜「Markdown」就能再打开它。
> 打开后建议点右上角 **预览**，对照下面「复制即用」的小块自己试。

## 这是什么、怎么打开本说明

- **Markdown** = 用几个符号给文字加格式（标题、粗体、列表……），保存成 `.md` 文件。
- Flyleaf 用标准 Markdown（不执行 HTML），另外支持 `[[双向链接]]` 和几种任务符号。
- **打开本说明**：`Ctrl+P` → 输入「Markdown」→ 选「打开 Markdown 写法说明」。
- 首次打开会在真库写入：`30-knowledge/Markdown写法说明.md`（已有则直接打开，**不覆盖**你改过的版本）。

---

## 标题

行首写 `#`，后面空一格，再写文字。`#` 越多标题越小。

```md
# 一级标题
## 二级标题
### 三级标题
```

**常见坑**：`#` 和文字之间要有空格。`#标题` 不会变成标题。

---

## 粗体 / 斜体

```md
这是 **粗体**，这是 *斜体*，也可以 ***又粗又斜***。
```

效果大致是：这是 **粗体**，这是 *斜体*。

---

## 列表与有序列表

无序（前面加 `-` 或 `*`，空一格）：

```md
- 苹果
- 香蕉
  - 香蕉里的小点（前面多两个空格）
```

有序（数字 + `.`）：

```md
1. 第一步
2. 第二步
3. 第三步
```

### 任务列表（Flyleaf 扩展）

列表项里写方括号，预览时会变成符号：

| 写法 | 预览符号 | 含义（可自定） |
| --- | --- | --- |
| `- [ ] 待办` | ○ | 未做 |
| `- [~] 进行中` | ◐ | 做到一半 |
| `- [x] 已完成` | ● | 做完 |
| `- [*] 重点` | ★ | 标星 |

复制即用：

```md
- [ ] 还没做
- [~] 正在做
- [x] 做完了
- [*] 特别重要
```

## 链接与图片（普通 Markdown）

普通网页链接：

```md
[点我打开官网](https://example.com)
```

图片（路径可以是 vault 里的相对路径，或网址）：

```md
![示意图说明](assets/demo.png)
```

## 双向链接 [[笔记名]]（Flyleaf 重点）

这是 Flyleaf 最常用的写法：在两篇笔记之间互相跳转。

```md
去看 [[深度测试]]
也可以写成 [[深度测试|点这里看深度测试]]
```

- `[[笔记名]]`：显示名 = 笔记名（一般对应文件名去掉 `.md`）。
- `[[目标|显示名]]`：跳到「目标」，界面上显示「显示名」。
- 右侧「反链」会列出谁链到了当前这篇。

**小提示**：目标名尽量和左侧文件树里的笔记标题一致，不然会找不到。

## 表格（实验笔记会用）

第一行表头，第二行用 `---` 分隔，后面是数据行。列用 `|` 隔开。

```md
| 版本 | 设备 | 帧时间(ms) | DrawCall | 显存(MB) |
| --- | --- | --- | --- | --- |
| before | 机型A | 16.7 | 120 | 180 |
| after | 机型A | 14.2 | 95 | 160 |
```

**常见坑**：

- 每一行左右最好都有 `|`。
- 分隔行 `| --- | --- |` 不能省。
- 列数要对齐（表头几列，下面就几列）。

---

## 代码块

行内代码：用反引号包起来：`` `变量名` ``。

多行代码块：上下各三个反引号：

````md
```text
这里面是代码或日志
不会被当成标题/列表去渲染
```
````

也可以标明语言，例如 \`\`\`csharp、\`\`\`glsl（主要是好看，Flyleaf 不强制）。

---

## 引用

行首写 `>`：

```md
> 这是一句引用。
> 可以连续多行。
```

---

## 分割线

单独一行写三个或更多 `-` / `*`：

```md
---
```

上面出现过的横线就是分割线。

## 踩坑五段小标题示例

新建「踩坑」笔记时，Flyleaf 会带这五段。也可以自己复制：

```md
## 症状

编辑器里正常，真机变成灰材质。

## 环境

UE 5.4.2 · Android Vulkan · Development 包

## 原因

材质实例某参数在打包时被剥离。

## 解法

在父材质勾选「用于材质实例」并重新打包。

## 验证

真机打开，参数与编辑器一致。
```

## 常见坑（对照改）

1. **空行**：标题、段落、列表之间适当空一行，预览才整齐。不要把所有内容挤成一大坨。
2. **标题后空格**：必须是 `# 标题`，不是 `#标题`。
3. **表格对齐**：分隔行 `| --- |` 要有；列数一致。
4. **双向链接括号**：是两个方括号 `[[...]]`，不是单个。
5. **任务方括号**：`- [x] 文字`，`[` `]` 和字母之间一般没空格；`- [ x ]` 可能不识别。
6. **HTML**：Flyleaf 关闭了 HTML，写 `<script>` / `<div>` 不会当网页执行，当普通文字处理更安全。

## 一张「最小可用」草稿（整段可抄）

````md
# 今天的笔记

先写一句 **结论**，再写细节。

## 做了什么

- [x] 复现问题
- [~] 查文档
- [ ] 写回实验表

相关：[[深度测试|深度测试笔记]]

## 数据

| 项 | 值 |
| --- | --- |
| 机型 | A |
| 帧时间 | 16ms |

> 下次先看反链，再改框架节点。

---

```text
日志或报错贴这里
```
````

写完切到 **预览** 看效果；不对就改符号，再预览。熟了以后这些符号会变成肌肉记忆。
